ssrf

服务器伪造请求

服务端提供从别的地方获取资源的功能点 如果可控就可能造成ssrf攻击内网

主要攻击服务集群中的内网服务

ssrf产生

远程加载图片或者下载图片

调用远程资源

共享 或者 分析资源时可能会重定向地址

php中的常见方法

攻击向量

支持多种协议

dict://ip:port/command

dict协议是一个字典协议 用来查询网络字典内容的应用层协议 走TCP协议

可以用来探测内网服务 访问的时候会携带少量数据 或者直接访问服务

只会回显有tcp回显的服务

gopher://ip:port/_<TCP原始数据>

可以发送tcp的原始数据 一般用来打post请求 或者是打某些服务 mysql redis

file 文件读取

http 超文本传输协议

ssrf利用

探测内网服务

使用dict协议+bp爆破 可以探测出底层使用tcp协议且会回显信息的服务 基本可以爆破出绝大部分服务

或者http协议扫内网web服务

打mysql

和直接打mysql没什么区别 只不过只能使用那几个协议
